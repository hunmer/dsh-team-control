# ADR-019：模型目录响应保留公开路由身份

- 状态：已接受
- 日期：2026-11-27
- 关联：[契约 §3.9](../CONTRACT.md#39-模型路由目录)、`src/llm.mjs`、`src/server.mjs`、`tests/llm-redaction.mjs`

## 背景

默认出口脱敏按敏感环境变量值做子串替换。公开 provider/model/effort 标识与这些值冲突时，目录里的真实路由会被改写，导致 Host 的精确路由校验拒绝派发。

## 决策

HTTP 路由元数据只为 `GET /api/llm/catalog`、`GET /api/llm/models`、`PATCH /api/llm/routes`、`PATCH /api/llm/providers` 指定响应策略。`redactLlmResponse` 先使用默认脱敏器，再在整体身份结构校验通过时复制已知身份字段；不修改原始目录。

保真字段和验证语义以契约 §3.9 为准。公开身份优先于凭据值子串匹配，但只在上述成功响应生效；不提供全局字段名豁免或 URL 前缀豁免。不符结构及未知策略回退完整脱敏。

## 安全与验证

错误路径不传响应策略。自由文本、未知扩展字段以及事件、审计、消息、SSE、日志、报告保持原有脱敏规则；调用者不能通过普通 payload 中的 `id/provider/model` 字段绕过。

回归测试使用独立生成的合成凭据，覆盖身份冲突、空值、不符结构、扩展字段、错误、工具发现与派发的激活参数，以及非目录通道；既有 AC-13 零泄漏断言不变。
