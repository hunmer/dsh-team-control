# 末班灯塔

最后一夜，风把海雾推上塔阶。停用的批文贴在值班室门上，接班的人昨天就走了，钥匙留给她。林晚挪开最后一只空油桶，在塔顶拾到一只铜铃。铃身发绿，比她还老，铃舌上刻着半个旧字。

她摇了一下。远处雾里亮起一盏灯，像有船在海上抬了一次头。她又摇，又一盏，光就停在雾里不肯走。铜铃每响一次，海上便多一盏归航的灯。她数到第九盏才明白：九——三年前雾季，值守簿上记着九条船的名字。她不是在点灯，她是在替失踪的船队指路。

停用那夜，铜铃自己响了。林晚推开塔门，循着灯光走下石阶，走进雾里。雾没有散，灯也没有灭。雾里有人应了一声，很轻，像旧船的木板。她没有回头——铃舌上那半个旧字，此刻烫得像刚落下的锚。
